Langkah Pembuatan Aplikasi

1. Membuat project Java baru pada Visual Studio Code.
2. Membuat package `Pertemuan1.Tugas1`.
3. Membuat class `main.java` sebagai class utama program.
4. Mengimpor library Java AWT dan Swing.
5. Membuat JFrame sebagai jendela utama aplikasi.
6. Membuat JPanel untuk mengelompokkan komponen formulir.
7. Menambahkan komponen GUI seperti JLabel, JTextField, JComboBox, JRadioButton, JCheckBox, JTextArea, dan JButton.
8. Mengatur tampilan menggunakan BorderLayout, GridLayout, dan FlowLayout.
9. Menambahkan ActionListener pada tombol Daftar dan Reset.
10. Mengatur Focus Traversal Policy untuk menentukan urutan perpindahan fokus.
11. Menjalankan aplikasi menggunakan Event Dispatch Thread (EDT).
12. Melakukan pengujian tampilan aplikasi, termasuk pengujian perubahan ukuran jendela.
13. Membuat laporan hasil uji
